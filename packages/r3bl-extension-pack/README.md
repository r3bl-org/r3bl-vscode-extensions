# R3BL Extension Pack

The complete R3BL development experience in one package! This extension pack includes:

- **[R3BL Theme](https://marketplace.visualstudio.com/items?itemName=R3BL.r3bl-theme)** - Custom dark theme optimized for Rust and Markdown
- **[R3BL Auto Insert Copyright](https://marketplace.visualstudio.com/items?itemName=R3BL.r3bl-auto-insert-copyright)** - Automatic copyright header insertion
- **[R3BL Semantic Configuration](https://marketplace.visualstudio.com/items?itemName=R3BL.r3bl-semantic-config)** - Enhanced Rust syntax highlighting (automatic)
- **[R3BL Task Management](https://marketplace.visualstudio.com/items?itemName=R3BL.r3bl-task-management)** - Task space management and context switching
- **[R3BL Copy Selection Path and Range](https://marketplace.visualstudio.com/items?itemName=R3BL.r3bl-copy-selection-path-and-range)** - Copy file path with selected line ranges in Claude Code format
- **[R3BL Fuzzy Search](https://marketplace.visualstudio.com/items?itemName=R3BL.r3bl-fuzzy-search)** - Fast fuzzy file search powered by fzf and ripgrep
- **[rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer)** - Official Rust language server

## What you get:
- ✅ Beautiful, carefully crafted dark theme
- ✅ Automatic copyright headers for new files
- ✅ Enhanced semantic highlighting for Rust (applied automatically)
- ✅ Task space management for organized workflows
- ✅ Quick file navigation with fuzzy search
- ✅ Copy file references with line numbers for AI assistants
- ✅ Full Rust language support via rust-analyzer
- ✅ Zero manual configuration required

## Installation

Install this extension pack and you'll get all the R3BL extensions automatically installed.

## Usage

1. Install this extension pack
2. Restart VSCode
3. Go to `File > Preferences > Color Theme` and select "R3BL Theme"
4. When prompted, click "Yes" to enable enhanced semantic highlighting
5. Start coding with the full R3BL experience!
