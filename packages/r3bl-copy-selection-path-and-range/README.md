# R3BL Copy Selection Path and Range

Quickly copy file paths with selected line ranges in multiple formats suitable for sharing with Claude Code and other tools.

## Documentation

For comprehensive documentation including features, output formats, keyboard shortcuts (Alt+o), and usage instructions, see the [R3BL VSCode Extensions Repository](https://github.com/r3bl-org/r3bl-vscode-extensions#r3bl-copy-selection-path-and-range).
