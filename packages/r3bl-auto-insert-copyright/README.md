# R3BL Auto Insert Copyright

Automatically includes copyright and license headers in your source code files. This extension saves time and cognitive energy by automating the process of adding copyright notices to new files.

## Documentation

For comprehensive documentation including features, supported languages, keyboard shortcuts, and configuration options, see the [R3BL VSCode Extensions Repository](https://github.com/r3bl-org/r3bl-vscode-extensions#r3bl-auto-insert-copyright).
